Cell notation: NAME = default function, NAME_n = AFIO remap value n (click it for the register bits that select it), NAME(AFn) = alternate-function number n, NAME? = route not stated by the datasheet. Confidence: ~ = one source only, ! = the two datasheet editions disagree, ? after a remap value = no selector field could be tied to it.
